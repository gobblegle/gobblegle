English Speller Database (ESDB, formerly SCOWL v2) by Kevin Atkinson
====================================================================

scowl-pre.txt is the complete, unchanged data file from ESDB:
  https://github.com/en-wl/wordlist  (branch v2, file data/scowl-pre.txt)
  last changed there on 2026-06-21, downloaded 2026-11-26.

Copyright.txt is ESDB's copyright and permission notice, copied word for word
from the Copyright file in the same repository. Keep it with scowl-pre.txt.

The Gobblegle board editor (editor.html) reads scowl-pre.txt when you click a
word in a word list, and shows that word's other forms, keeping only words that
are in the game dictionary (in_all_three_333k.txt).
